# Tic-Tac-Toe-game
##About the Project 
This is a Tic-Tac-Toe game built using HTML, CSS, JavaScript. Players take turns placing X and O on the board.
##Technologies Used
-HTML
-CSS
-JavaScript
##Features
-Interactive game board
-Two player gameplay
-Detects the Winner
-Detects a draw
